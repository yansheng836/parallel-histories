# 西侧卡片真实年份定位 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 西侧（西方）卡片按自己的真实年份在中轴上定位，使「左高右低」的落差如实反映中西事件的时间差。

**Architecture:** 为 32 张 `.card.west` 加 `data-date` 作为权威时间坐标；`layoutTimeline()` 中让西侧卡片脱离「按刻度堆叠」的定位规则，改由现成的 `yOfDate()` 独立定位（与分期色带同一机制）；中轴新增按年份滑动的 8px 圆点（连线保持水平），并消解同年卡片与 `.link-note` 的重叠。

**Tech Stack:** 原生 HTML/CSS/JS 单文件（`index.html`），零依赖不变。

**设计文档：** `docs/2026-09-24-西侧卡片真实年份定位设计文档.md`

## Task 1: 为 32 张西侧卡片加 `data-date`

**Files:**

- Modify: `index.html`（32 个 `.card.west` 加 `data-date`）

**取值表见设计文档 3.2。** 核心原则：有起年取起年、模糊年代取通行值、孤立单年事件取该年。

**关键约束：** `data-date` 必须随 DOM 顺序**非严格递增**（允许相等，如 #2/#3 同为 `-1100`）。

- [x] **Step 1: 用一次性 Python 脚本批量加属性（按卡片序号定位，幂等）**

在仓库根目录执行：

```bash
python - <<'PY'
import io,re
p='index.html'
s=io.open(p,encoding='utf-8').read()

# 32 张西侧卡片的 data-date，按 DOM 出现顺序（设计文档 3.2 表）
DATES=['-2000','-1100','-1100','-800','-334','-264','-27','395','527','622',
       '800','1066','1271','1453','1640','1765','1840','1861','1870','1897',
       '1914','1917','1929','1939','1946','1949','1962','1976','1981','1991',
       '2001','2016']

# 定位所有 <div class="card west"> 开标签（可能已带 data-date）
pat=re.compile(r'<div class="card west"( data-date="[-\d]+")?><i class="node"></i>')
found=pat.findall(s)
assert len(found)==len(DATES), f'期望 {len(DATES)} 张西侧卡片，实际 {len(found)}'

i=[0]
def repl(m):
    v=DATES[i[0]]; i[0]+=1
    return f'<div class="card west" data-date="{v}"><i class="node"></i>'
s2=pat.sub(repl,s)
io.open(p,'w',encoding='utf-8',newline='').write(s2)
print(f'已为 {i[0]} 张西侧卡片写入 data-date')
PY
```

预期输出：`已为 32 张西侧卡片写入 data-date`

- [x] **Step 2: 结构自检——属性齐全 + 单调性**

```bash
python - <<'PY'
import io,re
s=io.open('index.html',encoding='utf-8').read()
tl=s[s.index('<div class="timeline">'):s.index('<footer>')]

print('西侧卡片 non-monotonic:',bad)
# 刻度

print('刻度数:',len(ticks))

PY
```

预期：`西侧卡片数: 32`，两个 non-monotonic 均为空列表。

## Task 4: 中轴圆点与消重叠

> **原设计的「斜线」方案已被推翻**：斜线长度/角度随落差剧烈变化（几十到上千像素），
> 中轴附近从整齐的横线矩阵变成大角度扇形，反而更难读。最终方案是**连线保持水平，
> 只有中轴上的圆点按时间滑动**（设计文档 §5）。

**Files:**

- Modify: `index.html`（新增 `.axis-node` 规则 + `layoutTimeline()`）

- [x] **Step 1: 新增 `.axis-node` CSS**

`left:50%` + `translate(-50%,-50%)` 与 `.axis` 同轴对齐。**漏掉 `left:50%` 会让圆点落到容器左缘。**

- [x] **Step 2: JS 创建圆点**

两侧统一：`nodeY = yOfDate(year) + LINK_T`（中国侧 `year` 来自 `cnYearOf()`，西侧来自 `data-date`）。
卡片 `top = nodeY − LINK_T − iy`，使 `::after`（卡片内 `top:24px`）正好横向触到圆点。**单调性校验必须分同一侧**，不要把「一行内中国侧晚于西侧」误判成倒序。

- [x] **Step 3: 消重叠**

两种遮挡都要处理：两张同年卡片（前1100 × 2）、与居中 `.link-note` 抢位置。
比对时卡片实际占 `[nodeY−LINK_T, nodeY−LINK_T+h]`——`nodeY` 是连接点不是顶边，漏掉换算会漏判。

- [x] **Step 4: 验证**

65 个圆点与卡片的连接线 y 一一对应（集合比对，误差 ≤1.5px）；西侧圆点严格按时间递增。
